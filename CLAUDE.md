# hitl-mfa-lab

Demo-tier standalone app: an agent's money movement is gated by a mock authorization policy — amount bands decide PERMIT / HITL consent / MFA step-up / hard DENY, and CIBA requests out-of-band approval on the user's own phone for a sensitive agent-initiated action, regardless of amount. Approvals are single-use, amount-bound receipts; the MFA credit has a 5-minute TTL. Standalone mock of the AI-DEMO2 HITL track (UC7/UC8/UC22, `authorizeObligations` / `hitlCredit` / CIBA services).

- Run: `./scripts/run.sh` (http://localhost:7680). Test: `npm test` (server is `node --test test/*.test.js`, a glob). Preflight: `npm run doctor`. Reset: `npm run reset`.
- Core: `server/src/policy.js` (pure `evaluateAmountPolicy`, `normalizeBands`, `classifyObligation(s)`, `createReceiptStore`, `createCibaStore`). Story data `server/src/policyData.js` with `{{castBrand}}`-style tokens filled by `cast.js` (3 vertical packs); a test fails on an undefined token. Diagram: `server/diagrams/hitl-mfa-flow.json` (diagram-studio/1).
- API: `GET/POST /api/policy` (bands; a crossing edit falls back to defaults, never wider), `POST /api/transfer` (428 human beat / 403 deny / 200 permit), `POST /api/mfa/challenge|verify` (demo OTP 123123), `POST /api/ciba/bc-authorize`, `GET /api/ciba/poll/:authReqId`, `POST /api/ciba/respond`, `GET /api/runs`, `POST /api/reset`, `GET /api/info`, `POST /api/mode` (rule 19; 409 when Real unconfigured), `GET /api/health` (demo-health/1). Workspace id in `X-Workspace`.
- Decision contract (do not weaken): DENY > STEP_UP > HITL (highest gate wins); most-specific classification (HITL_CONSENT before HITL); a receipt discharges its gate for exactly ONE retried call and only at or below its bound amount; declared step-up (`ciba`/`p1mfa`) is amount-independent but still below a hard DENY; an unknown band value falls back to the DEFAULTS, never wider.
- Rules that bite: loopback bind only; same-origin writes; zero outbound network (netguard); only `.example`/`.invalid` hosts; ports 7680-7689; the demo OTP and every decision value shown raw and labelled mock; `POST /api/mode` is exactly `{ source: "mock"|"real" }`.
- Web: `web/src/App.jsx` (tabs, presenter, Reset, X-Workspace via `workspace.js`), `components/PolicyGate` (bands editor, agent call with the declared step-up, consent modal + auto-retry, MFA modal, CIBA phone panel, verdict + hops), `DiagramTab` + `PatternDiagram` (from the scaffold). Colours come from `tokens.css` only. Test: `npm test -w web` (vitest + RTL, mocked fetch).
- Trace: `server/src/trace.js` builds W3C traceparent for every mock hop in `/api/transfer` (hops differ by decision: PERMIT 2+, HITL 3, STEP_UP 3, CIBA 5).
